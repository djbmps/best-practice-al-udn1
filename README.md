# ระบบส่งผลงานแนวปฏิบัติที่เป็นเลิศ (Best Practice) ประจำปีงบประมาณ 2569

**สำนักงานเขตพื้นที่การศึกษาประถมศึกษาอุดรธานี เขต 1**

ระบบรับส่งผลงานแนวปฏิบัติที่เป็นเลิศ ใช้ Google Sheet เป็นฐานข้อมูล
และ Google Drive เป็นที่จัดเก็บไฟล์ผลงาน

เปิดรับผลงาน **ตั้งแต่บัดนี้ ถึงวันที่ 24 สิงหาคม 2569**
(อ้างถึงหนังสือ ที่ ศธ 04176/ว3417 ลงวันที่ 17 สิงหาคม 2569)

## ประเภทผลงานที่รับการคัดเลือก

| ที่ | ประเภท | ไฟล์ที่ต้องส่ง |
|---|---|---|
| 1 | แนวปฏิบัติที่เป็นเลิศในการจัดการเรียนรู้เชิงรุก (Active Learning) — 8 กลุ่มสาระ | แผนการจัดการเรียนรู้ (PDF) · ลิงก์คลิปการสอน · อินโฟกราฟิก (PDF/JPG/PNG) |
| 2 | แนวปฏิบัติที่เป็นเลิศ ด้านการบริหารสถานศึกษา | อินโฟกราฟิก 1 ชิ้น (PDF/JPG/PNG) |
| 3 | แนวปฏิบัติที่เป็นเลิศ ด้านการจัดการเรียนรู้ | อินโฟกราฟิก 1 ชิ้น (PDF/JPG/PNG) |

> ประเภทที่ 2 และ 3 สำหรับโรงเรียนที่มีผลสัมฤทธิ์ทางการเรียนสูงกว่าระดับประเทศ
> ต่อเนื่อง 3 ปีการศึกษา (2566–2568)

## คุณสมบัติ

**หน้าครูผู้สอน**

- เลือกประเภทผลงาน 3 ประเภท ระบบแสดง/ซ่อนช่องกรอกและไฟล์แนบให้อัตโนมัติ
- กลุ่มสาระการเรียนรู้ **8 กลุ่มสาระ**
- กรอกคำนำหน้า ชื่อ-สกุล ตำแหน่ง วิทยฐานะ เบอร์โทรศัพท์ ID Line
- เลือก **กลุ่มโรงเรียน** แล้วรายชื่อ **โรงเรียนในกลุ่ม** แสดงให้เลือกอัตโนมัติ
- อัปโหลดแผนการจัดการเรียนรู้ (PDF) และอินโฟกราฟิก (PDF/JPG/PNG) ไม่เกินไฟล์ละ 10 MB ลากวางได้ มีภาพตัวอย่าง
- กรอกลิงก์คลิปการสอน
- ตรวจสอบความถูกต้องทั้งฝั่งเว็บและฝั่งเซิร์ฟเวอร์ + แสดงรหัสอ้างอิงเมื่อส่งสำเร็จ
- **ตารางผลงานที่ส่งเข้ามาแล้ว** ให้ผู้ส่งตรวจสอบได้ว่าผลงานเข้าระบบเรียบร้อย (ไม่แสดงเบอร์โทรศัพท์ ID Line และไฟล์แนบ)
- รองรับคอมพิวเตอร์ แท็บเล็ต และมือถือ

**หน้าผู้ดูแลระบบ**

- เข้าระบบด้วยรหัสผ่าน
- การ์ดสรุปจำนวนผลงาน / โรงเรียน / กลุ่มโรงเรียน / กลุ่มสาระ
- ค้นหาข้อความ กรองตามประเภทผลงาน / กลุ่มสาระ / กลุ่มโรงเรียน / ระดับชั้น เรียงลำดับได้
- เปิดไฟล์แผนการสอน อินโฟกราฟิก และคลิปการสอนในคลิกเดียว
- ส่งออก CSV รองรับภาษาไทย เปิดใน Excel ได้ทันที
- ซ่อนรายการทดสอบระบบ (ชื่อผลงานขึ้นต้นด้วย `TEST-`) — พิมพ์ `test` ในช่องค้นหาเพื่อแสดง

## การติดตั้งโดยย่อ

1. สร้าง Google Sheet เปล่า และโฟลเดอร์ Google Drive → คัดลอก ID ทั้งสอง
2. นำ `Code.gs` ไปวางที่ [script.google.com](https://script.google.com) แก้ค่า 3 บรรทัดบนสุด
   (`SHEET_ID`, `FOLDER_ID`, `ADMIN_PASS`)
3. Deploy เป็น **เว็บแอป (Web app)** โดยตั้ง
   **ดำเนินการในฐานะ: ฉัน (Me)** และ **ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน (Anyone)**
4. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ในตัวแปร `API_URL`
   ของทั้ง `index.html` และ `admin.html`

รายละเอียดทั้งหมดอยู่ใน [`คู่มือการติดตั้ง.md`](คู่มือการติดตั้ง.md)
